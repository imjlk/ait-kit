# @ait-kit/api-orpc

Typed oRPC schemas and public router helpers for Apps in Toss gateways.

```bash
npm install @ait-kit/api-orpc
```

```ts
import { publicRouter } from "@ait-kit/api-orpc";
```

The router delegates Apps in Toss operations to an `AppsInTossApiRpc` context. See the
[AIT Kit repository](https://github.com/imjlk/ait-kit) for the Cloudflare Pages gateway example.
